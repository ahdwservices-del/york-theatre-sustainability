# Theatre sustainability

Static site of operating theatre sustainability resources.

- `index.html` – home, **Which bin?** waste finder (`#waste-finder`), York low flow project (`#low-flow`), Scarborough low flow project (`#low-flow-scarborough`), Bridlington low flow project (`#low-flow-bridlington`); posters in `img/`
- `why-bother.html` – Why should I bother? Climate and health for patients, staff, hospital and community; the triple win (update the headline figures when UKHSA/Lancet Countdown publish)
- `boundaries.html` – interactive planetary boundaries wheel (Planetary Health Check 2026 figures; update `boundaries-data.js` each September – it also feeds the table on the reading page)
- `sixrs.html` – the 6 Rs wheel, quiz and printable action list
- `quiz.html` – Which bin? quiz
- `propofol.html` – Plan Your Propofol poster
- `reading.html` – Additional reading: detail, evidence and sources kept off the main pages
- `roadmap.html` – Green Theatres Roadmap: 42 actions with case-example links and volunteer sign-up
- `drug-waste.html` – Drug waste audit: logs syringes drawn up but not used (site, theatre, drug, propofol volume, optional reason) to the "Drug waste" tab of the Apps Script sheet. Not in the main nav; reach it by QR code. Theatre lists live in both the page and `Code.gs`
- `apps-script/Code.gs` – Google Apps Script backend for volunteer sign-ups (emails the project lead, returns public names)

Waste guidance follows HTM 07-01. Local waste policy and bin labels take precedence.
The site holds no patient or organisational data. Do not put real email addresses in this repository.
